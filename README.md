# ArquiVisionPy

Librería en Python para detectar líneas, esquinas e intersecciones en planos arquitectónicos digitalizados.

## Descripción

Este proyecto analiza imágenes de planos arquitectónicos o croquis escaneados mediante técnicas de procesamiento digital de imágenes.

El sistema aplica:

- Preprocesamiento de imagen
- Conversión a escala de grises
- Filtrado espacial
- Umbralización
- Transformación afín
- Detección de bordes con Canny
- Detección de líneas con Transformada de Hough
- Detección de esquinas
- Detección de intersecciones
- Marcado visual de resultados
