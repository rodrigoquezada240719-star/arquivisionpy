# ArquiVisionPy

Librería en Python para detectar líneas, esquinas e intersecciones en planos arquitectónicos.

## Instalación

pip install -e .

## Uso

Ejecutar en Spyder:

examples/demo_spyder.py

## Funcionalidades

- Preprocesamiento (grises, blur, threshold)
- Detección de bordes (Canny)
- Detección de líneas (Hough)
- Detección de esquinas
- Detección de intersecciones
- Transformación afín (rotación)

## Resultados

- Líneas: verde
- Esquinas: rojo
- Intersecciones: azul
